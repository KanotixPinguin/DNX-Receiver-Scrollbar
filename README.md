# DNX Receiver Scrollbar

Sichtbare grüne Scrollleiste für umfangreiche OpenWebRX-Receiver-Panels. Begrenzt das Panel auf die Bildschirmhöhe, ermöglicht Mausrad-/Touch-Scrollen, verhindert horizontales Scrollen und verwendet eine leuchtende grüne Scrollspur mit Hovereffekt.

## Installation

```bash
chmod +x install.sh
sudo ./install.sh install
```

## Status / Update / Entfernen

```bash
./install.sh status
sudo ./install.sh update
sudo ./install.sh uninstall
```

Backups: `/opt/dnx-receiver-scrollbar-backups`.

## Hinweis

Rein privates, unabhängiges Hobbyprojekt. Kein offizielles OpenWebRX-/OpenWebRX+-Projekt oder Plugin. Nutzung auf eigene Gefahr; soweit gesetzlich zulässig keine Haftung. Vorher Backups erstellen und auf einem Testsystem prüfen.
